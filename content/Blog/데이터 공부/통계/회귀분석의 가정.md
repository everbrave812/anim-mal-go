## 4. 회귀진단

> “우리가 만든 회귀선, 과연 믿을 수 있을까?”

통계 모델은 언제나 몇 가지 **전제조건(가정)** 위에 서 있다. 그 가정들이 무너지면,

겉보기엔 멀쩡해 보여도 실제론 왜곡된 결과를 내는 회귀모형이 될 수 있다.

즉, **가정을 확인하지 않은 회귀모형은 모래 위에 지은 집과 같다.** 그래서 이번 장에서는 **회귀모형이 제대로 작동하고 있는지를 진단하는 방법**, 즉 ‘회귀진단(Regression Diagnostics)’에 대해 이야기해보려 한다. 여기서는 회귀분석의 4가지 핵심 가정을 살펴보고, 이를 검토하기 위한 **시각적 진단 방법**과 **이상치/영향점 처리법**까지 함께 다룰 것이다.

## 4.1. 회귀분석의 4가지 가정, 잔차의 종류들

1\) 선형성 가정 (Linearity)

설명변수 x와 반응변수 y는 선형적으로 연결되어야 한다.

즉, 평균 반응이 x에 따라 **직선적으로 변화**해야 한다.

2\) 오차항 가정 (iid 가정)

오차항 ε은 아래의 조건을 모두 만족해야 한다:

> Independently (독립적)\
> Identically (동일 분포)\
> Distributed (분포 형태 일정)

즉, 오차항은 서로 독립이며, 동일한 정규분포를 따라야 하고, 분산 또한 일정해야 한다.

이 가정에서 파생되는 주요 개념은 다음과 같다 -> 앞으로 다음을 주로 확인할거다 

|  |  |  |
| --- | --- | --- |
| ① | **독립성** | 자기상관 (Autocorrelation) |
| ② | **정규성** | 비정규분포 (Normality violation) |
| ③ | **등분산성** | 이분산성 (Heteroscedasticity) |

iid 가정이 어긋나는 경우로 확인후, 가정을 맞추기 위한 전처리를 진행해줘야 한다

3\) **예측변수 x에 대한 가정**

x는 고정되어 있거나 선택된 값

> 실험 설계에 따라 설정된 값일 수도 있고, 관찰값일 수도 있음.\
> 이 경우, 예측변수에 오차가 포함되지 않아야 함.

 

x는 오차 없이 정확히 측정된 값

> **측정오차가 있으면 회귀계수의 신뢰도가 떨어짐. -> 당연한 이야기다...** \
> 특히, 센서 오차, 설문조사 오차 등이 예시.

사실  선택된 값을 안다거나 오차없이 측정된 값이라는걸 아는건 좀 힘들다, 따라서 실무적인 측면에서 이를 고려하는 경우는 드물다

중요한건 다음에 나오는 공선성 문제이다

예측변수 간 다중공선성이 없어야 함

> x 변수들끼리 서로 독립적이어야 함. (변수간 상관성이 없다) \
> 다중공선성이 심하면 회귀계수 추정이 불안정해짐 **→ OLS 의 유일성 보장이 안됨** 

 

4\) **관측값들은 독립적이며 대표성을 가져야 함**

> 수집된 데이터는 모집단을 잘 대표할 수 있어야 하고, 서로 독립적인 관측이어야 한다.\
> 특정 표본에만 의존하거나 의도적으로 선택된 데이터는 분석 결과의 일반화를 막을 수 있다.\
> 실험이든 관측연구든, 샘플링 전략과 설계가 중요한 이유다.

회귀결과 도출에 동등한 역할을 한다. 

## 4.2. 가정 확인

우리가 확인해야 하는 가정을 다시한번 보자 

> 1. 정규성 확인 : 잔차가 정규분포를 따른다고 가정
> 2. 선형성 확인 : 설명변수 x와 반응변수 y는 선형적으로 연결되어야 함 
> 3. 독립성 확인 : 각 관측치는 서로 독립이어야 함
> 4. 등분산성 확인 : 잔차의 분산이 일정해야 함(패턴을 보이면 안됨)
> 5. 공선성 확인 : 설명변수들 간에 강한 상관관계가 없어야 함

\+ 이상치, 특이값 (4.3 이상치 제거로 따로 다룰 예정)

하나씩 확인해보자 

#### 1. 정규성 확인 : 잔차가 정규분포를 따른다고 가정

> 확인 방법 : **Q-Q plot 을 통해 진단한다**

![](../../../Attachments/Tistory/37-02.png)

이미지에서 확인할 수 있듯, 정규성을 띄는 경우 우상향 대각선을 기준으로 점들이 나란히 붙어 있는 것들을 확인할 수 있다. -> 정규성 만족

#### 2. 선형성, 등분산성 확인

설명변수 x와 반응변수 y는 선형적으로 연결되어야 함

잔차의 분산이 일정해야 함(패턴을 보이면 안됨)

> 확인방법 : 잔차 플롯을 통해 진단한다 

![](../../../Attachments/Tistory/37-03.png)

잔차플랏 하나로 선형성, 등분산성 모두를 확인할수 있다.

다음 잔차플롯에서 선형성과 등분산성을 만족시키는 그래프는 어떤걸까? 

정답은 가장 좌측의 그래프이다. 이제 그 설명을 하도록 하겠다 

> 1번째, 가장 좌측 그래프의 경우 \
> **잔차들이 랜덤하게 흩어져 있음**\
> **특정 패턴 없음 → 선형 모델 적합 잘 됨**\
> **분산도 일정함 → 등분산성도 OK**

> 2번째 그래프의 경우 \
> **잔차가 곡선 패턴을 보임 -> 선형성 위배**\
> **직선보다는 곡선(예: 2차 함수)이 더 적합할 가능성**

> 3번째 그래프의 경우 \
> **X가 커질수록 잔차의 폭이 점점 벌어짐**\
> **즉, 분산이 커짐 → 이분산(heteroscedasticity) 발생 -> 등분산성 위배**

#### 2. 독립성 (Independence) 확인

**관측값이 서로 독립적으로 수집**되어야한다 \
하지만 현실에서는 특히 **시계열 데이터(time-series)** 에서 이 조건이 자주 깨진다.

> 확인방법 : 더빈왓슨 테스트를 통해 진단한다

> DW 값 ≈ 2: 자기상관 없음 (독립성 만족)\
> DW < 1.5: 양의 자기상관 의심\
> DW > 2.5: 음의 자기상관 의심

잔차 플롯으로도 확인이 가능하다, 시계열 데이터가 그 대표적인 예시이다

> 잔차 vs 시간(time) 그래프에서 잔차가 일정한 방향성을 보이면 독립성 위배 가능성 ↑ \
> → 실제로는 잔차가 랜덤하게 움직여야 함

#### 5. 다중공선성  (Multicollinearity) 확인

다중공선성 이라는 말 자체가 아마 생소할거 같다

**다중공선성(multicollinearity)이란,** \
여러 개의 설명변수들 간에 **강한 상관관계**가 있을 때 발생하는 문제다.

이게 왜 문제일까?

회귀계수 추정값이 불안정해지고/ 해석이 어려워지며\
불필요한 변수들이 모델에 들어갈 수 있다

따라서 꼭 공선성 확인을 해야한다

> 확인방법 : VIF (Variance Inflation Factor)를 통해 진단한다

> VIF < 5: 문제 없음\
> VIF > 5: 다중공선성 의심\
> VIF > 10: 매우 심각

## 회귀진단 정리

회귀모형을 믿기 전에 반드시 확인해야 할 5가지 주요 가정들.\
각각의 가정이 의미하는 바와 확인 방법을 아래와 같이 정리해봤다:

|  |  |  |  |
| --- | --- | --- | --- |
| **1. 정규성 (Normality)** | 잔차는 정규분포를 따라야 함 | Q-Q Plot | 신뢰구간 및 p-value 신뢰도 하락 |
| **2. 선형성 (Linearity)** | x와 y의 관계는 선형이어야 함 | 잔차 플롯 | 모델이 관계를 제대로 반영하지 못함 |
| **3. 등분산성 (Homoscedasticity)** | 잔차의 분산이 일정해야 함 | 잔차 플롯 | 특정 구간의 예측 신뢰도 저하 |
| **4. 독립성 (Independence)** | 관측값은 서로 독립이어야 함 | Durbin-Watson Test, 잔차 시계열 그래프 | 자기상관 → 예측 왜곡 |
| **5. 다중공선성 (Multicollinearity)** | 설명변수들끼리 강한 상관 없어야 함 | VIF | 회귀계수 추정 불안정, 해석 불가능 |

회귀분석의 가정진단은 정말 중요한 파트이다. 다음시간에는 가정이 어긋났을때 어떻게 처리를 해야하는지에 대해 알아보도록 하자
